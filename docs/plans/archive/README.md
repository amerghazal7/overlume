# Archive

The June/July 2026 plans and specs here (`2026-06-19-*`, `2026-06-23-*`,
`2026-07-06-*`) describe the retired NumPy, OpenGL, and CUDA prototypes that
predate the Filament-based `overlume` library — kept as history, not as
current documentation; every path inside them is pre-restructure (see the
path map in `docs/README.md` / `docs/plans/2026-09-17-overlume-restructure.md`)
and is intentionally left unedited. `visual_mode_project_backlog.md` is a
different kind of historical document: an Azure DevOps import staging table
for the (non-retired) Filament visual-mode work, superseded by
`docs/status.md` as the single status ledger.
